# AngularJS Project Demo

A Frontend Web Development project built using AngularJS to demonstrate the core concepts of the AngularJS framework. This project contains multiple demo pages that explain important AngularJS features such as data binding, directives, routing, events, HTTP services, forms, and conditional rendering.

# Project Overview

The AngularJS Project Demo is a collection of practical examples designed to learn and understand AngularJS fundamentals. Each HTML page demonstrates a specific AngularJS concept, making the project a useful reference for beginners exploring client-side web development.
